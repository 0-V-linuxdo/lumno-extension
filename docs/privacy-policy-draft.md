# Lumno 隐私政策

开发者/数据控制者：中文为“枯白啃设计”，其他语言为“Kubai087”
隐私与安全联系邮箱：i@kubai.design
适用版本：Lumno 0.9.30 及以上

> 本文按照当前产品实现编写，不构成针对特定司法辖区的法律意见。产品处理方式发生变化时，应同步更新本文、产品内披露和应用商店声明。

## 1. Lumno 处理哪些数据

### 本地功能数据

为提供书签搜索、历史搜索、新标签页、画中画和其他浏览器功能，Lumno 会在用户设备本地读取或保存相关数据。除下列账号同步及随之启用的产品使用统计外，这些浏览器数据不会发送到 Lumno 的服务器。

### 账号与识别数据

当你在插件内确认开启账号同步并继续登录时，Lumno 处理你的邮箱、所选 Google 或 GitHub 登录方式、系统生成的用户 ID、设备 ID、插件版本、浏览器家族和粗粒度平台类型，用于登录、安全和跨设备同步。如果 Google 与 GitHub 返回同一个已验证邮箱，Supabase 可能把两种身份自动关联到同一 Lumno 账号。

### 同步数据

当你在插件内确认并完成登录后，Lumno 会同步你主动创建或修改的 Lumno 配置，包括主题、布局、自定义快捷方式、站内搜索提供商、黑名单规则、功能开关和壁纸选择。其中可能包含你主动填写的 URL、名称或规则文本。

### 媒体数据

当你主动导入自定义壁纸或为快捷方式设置自定义图标且已登录时，Lumno 会上传相应图片、壁纸缩略图、关联的快捷方式标识、显示名称、文件类型、尺寸、字节数和文件哈希，用于跨设备恢复。

图片会先在你的设备上缩放并重新编码，随后由服务端复核格式、尺寸和字节数。为防止云媒体功能被用于存储违法、有害或明显与扩展无关的内容，服务端会把待上传图片发送给内容安全处理方进行分类；审核未明确允许时，图片不会写入 Lumno 的活动媒体存储。正式启用云媒体前，本节必须补充该处理方的法定名称、处理区域、保留期和申诉联系方式；未补齐时云媒体上传保持关闭。

### 产品使用统计

插件会在跳转至网页登录前一次性说明账号同步和产品使用统计的数据范围。只有在你确认并完成登录后，Lumno 才会同时开启同步，并记录和上传功能使用次数以及配置的布尔值、枚举和数量。该通道不上传 URL、域名、路径、搜索词、网页标题、浏览历史、书签内容、邮箱、Cookie 或认证 Token。退出登录会停止新的统计记录和上传，并清除本机待上传计数。

### 服务日志

Supabase 可能为了安全、可靠性和故障排查处理请求时间、服务、路由、响应状态、IP 地址及账号或请求标识等有限日志。当前 Free 计划的 API 与数据库日志保留 1 天。Lumno 不另行部署错误监控、日志导出或客服数据平台。

## 2. 使用目的

Lumno 仅将上述数据用于：

- 提供用户选择的 Google 或 GitHub 登录方式，并在已验证邮箱相同时关联身份；
- 提供账号级跨设备配置、壁纸和快捷方式自定义图标同步；
- 维护同步一致性、发现冲突和防止重复写入；
- 在用户确认开启账号同步时，以聚合数据改进 Lumno 功能和可靠性；
- 防止滥用、保护账号和排查故障；
- 履行适用法律义务。

Lumno 不出售用户数据，不将数据用于广告定向，也不使用浏览活动建立用户画像。

## 3. 数据共享与处理方

Lumno 仅在提供上述功能所必要时使用以下处理方：

- 内容安全处理方：**上线前待填写**；仅处理用户主动上传、已压缩的壁纸或快捷方式图标，用于违法有害内容和服务滥用检测。未完成处理方披露前不启用生产云媒体上传。

- Supabase（当前项目区域：日本东京）：身份认证、数据库、文件存储、Edge Functions 和有限服务日志；
- Google：在用户选择 Google 登录时提供基础账号身份认证；
- GitHub：在用户选择 GitHub 登录时提供基础账号身份认证；

数据也可能在法律要求、保护用户或防止欺诈滥用时依法披露。

## 4. 保存期限

- 账号和同步数据：保留至用户删除相关数据或永久删除账号；
- 已删除的壁纸或快捷方式自定义图标：收到删除请求后从活动存储和 metadata 中删除，备份中的残留依服务商备份周期清除；
- 与账号关联的每日产品使用统计及配置属性：自对应日期起保留 24 个月，之后自动删除；
- 长期趋势统计：在删除账号关联明细前，仅按“月份和功能指标”汇总总次数，不包含用户 ID、设备 ID、邮箱、配置属性或其他个人标识；该匿名汇总可以长期保留；
- 统计上传的去重批次标识：保留 30 天；同步写入的去重操作记录：保留 90 天；
- Supabase API 与数据库日志：当前计划保留 1 天；若服务计划变化，按届时生效的服务商期限执行并更新本文；
- 用户退出登录后，本机待上传计数立即清除，之后不再创建新计数；再次确认并登录后才重新启用。

## 5. 安全

Lumno 使用 HTTPS 传输数据；业务表启用 Row Level Security；媒体 Bucket 为私有；高权限 Secret Key 仅保留在服务端。插件登录使用 OAuth 2.1 Authorization Code + PKCE；认证 Token 只保存在当前设备扩展源私有的 IndexedDB 中，不进入 Chrome 同步，普通网页和内容脚本不能直接读取。

任何系统都无法保证绝对安全。如发现安全问题，请联系 i@kubai.design。

## 6. 用户控制与删除

你可以在 Lumno 的“账号与隐私”页面：

- 查看登录与同步状态；
- 手动同步；
- 退出登录以停止账号同步和产品使用统计，并继续使用游客模式；
- 永久删除账号、云端配置、媒体和统计聚合。

永久删除账号不会自动删除设备上的本机配置。你可以通过浏览器扩展管理页面清除 Lumno 的本地数据或卸载扩展。

如需访问、更正、导出或删除无法在产品内处理的数据，请联系 i@kubai.design。

## 7. 儿童

Lumno 面向一般用户，不专门面向 13 周岁以下儿童。未达到所在地区可独立同意个人信息处理年龄的用户，应在监护人同意和指导下使用账号、同步及统计功能。若发现未经适当同意处理了儿童个人信息，请联系 i@kubai.design 删除。

## 8. 跨境与地区

Lumno 面向全球用户。账号、同步和媒体数据主要存放在 Supabase 日本东京区域；Supabase、Google 和 GitHub 可能在用户所在国家或地区以外处理身份或服务日志。Lumno 通过本政策告知跨境处理，并在适用时依赖履行服务所必需的处理、用户同意以及服务商提供的数据保护条款和合法传输机制。

## 9. 政策变更

如数据处理方式发生重大变化，Lumno 会更新本政策，并在扩展界面中进行显著说明；需要时会重新取得用户同意。

## 10. Chrome Web Store Limited Use

Lumno 对从浏览器 API 和 Google API 获得的信息的使用将遵守 Chrome Web Store User Data Policy，包括 Limited Use 要求。Lumno 仅在提供或改进已明确披露的单一用途所必要的范围内使用用户数据，不出售数据、不用于个性化广告，也不允许人工读取用户内容；仅在用户针对具体支持请求明确同意、安全调查、履行法律义务，或数据已经聚合匿名化并用于内部运营时例外。

参考：[Chrome Web Store User Data FAQ](https://developer.chrome.com/docs/webstore/program-policies/user-data-faq/) 和 [Privacy Policies](https://developer.chrome.com/docs/webstore/program-policies/privacy)。
