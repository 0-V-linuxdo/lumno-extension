# Retired email OTP authentication

This directory preserves the email one-time-code implementation retired on
2026-08-02. It is outside `src/` and `supabase/`, so it is not bundled,
deployed, or reachable from the Lumno product.

Restoring it requires a new product and privacy review, re-enabling Supabase
email authentication, restoring an audited email template and delivery
provider, and adding current abuse controls. Do not copy it back piecemeal.
